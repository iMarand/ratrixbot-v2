Ratrix Bot v2

An advanced, self-learning, multi-indicator trading engine for Deriv synthetic indices. Built entirely in high-performance C++ using Reinforcement Learning (Q-Learning) and massive grid-search optimization.

Disclaimer

Ratrix Bot v2 is built for paper trading and historical backtesting. Synthetic indices are RNG-generated. Always test out-of-sample before risking capital.

Compilation

Ratrix Bot v2 (R-bot 2) is entirely self-contained. It only requires g++ and the standard networking libraries to compile.

Windows (MSYS2) Compilation

g++ derivbot.cpp -o derivbot.exe -std=c++17 -lssl -lcrypto -lws2_32 -lwsock32

Linux Compilation

g++ derivbot.cpp -o derivbot -std=c++17 -lssl -lcrypto -lboost_system

Training & Reinforcement Learning

The crown jewel of Ratrix Bot v2. The training engine downloads tick history, runs thousands of grid-search parameter combinations across 6 distinct strategies, and uses a Q-Learning meta-agent to figure out exactly which strategies perform best under current market regimes (Trend, Volatility, Momentum).

Continuous Learning Mode

This command runs the training engine in an infinite loop. It will train, save the "brain", sleep for 5 minutes, and train again. Perfect for running on a VPS.

./derivbot.exe --train --symbols jump10,jump25,v75 --autoadjust

Time-Boxed Training

Limit the training loop to a specific number of hours.

./derivbot.exe --train --symbols jump10 --autoadjust --train-hours 4

Backtesting

Run isolated tests on specific historical windows to verify a strategy manually.

Standard Backtest

Backtest the powerful Multi-Confluence strategy with 10,000 historical ticks.

./derivbot.exe --mode backtest --symbol jump10 --strategy multi_confluence --count 10000

Load from Trained AI

Instead of manually typing all the parameters, load the #1 best strategy perfectly from a previous training run.

./derivbot.exe --mode backtest --symbol jump10 --load-run run_20260621_234305 --rank 1

Paper Trading

Listen to the live WebSocket feed and execute trades virtually to track P&L in real-time.

Live Execution

./derivbot.exe --mode paper --symbol jump10 --load-run run_20260621_234305 --rank 1 --csv my_trades.csv

Cooldown Gate

Prevent the bot from over-trading by setting a mandatory cooldown (in seconds) between signals.

./derivbot.exe --mode paper --symbol v75 --strategy macd --cooldown 60

Results Management

Manage the massive amounts of data generated by the Training Engine.

# View all completed training runs and the symbols they tested
./derivbot.exe --list-runs

# Delete a specific, outdated run to save disk space
./derivbot.exe --delete-run run_20260621_234305

# Wipe the slate clean and delete all runs
./derivbot.exe --delete-all-runs

All CLI Flags

A comprehensive list of every configuration flag available in Ratrix Bot v2.

Flag Description
--mode <mode> backtest | paper
--train Enters training mode (bypasses --mode)
--symbol <sym> The target market symbol (e.g., jump10, v75)
--strategy <name> rsi | ema_cross | macd | bollinger | stochastic | multi_confluence
--duration <sec> Contract duration in seconds (15 or 30). Default: 15
--stake <amt> Virtual stake size for P&L tracking. Default: 1.0
--cooldown <sec> Minimum seconds between executing trades. Default: 0
--load-run <id> Loads strategy parameters from a saved JSON run (e.g., run_20260621_234305)
--rank <n> Loads the Nth best strategy when using --load-run. Default: 1

Training Specific Flags

Flag Description
--symbols <list> Comma separated list for batch training (e.g., jump10,v75)
--all-symbols Trains the AI on every single active market Deriv offers.
--autoadjust Enables the 5-minute continuous loop learning mode.
--train-hours <n> Auto-stops the autoadjust loop after N hours.
--top-k <n> How many top strategies to export to JSON. Default: 10

Best Workflows

The Golden Loop

The most powerful way to use Ratrix Bot v2 is to let it optimize itself overnight.

Step 1: Set and Forget Training
Run this command before you go to sleep. It will continually adapt to the market all night.

./derivbot.exe --train --symbols jump10,jump25,jump50,v75,v100 --autoadjust

Step 2: Review in the Morning
Wake up and see what the AI accomplished.

./derivbot.exe --list-runs

Step 3: Deploy the Best Engine
Take the latest timestamped run ID, and deploy the #1 ranked strategy directly into the live paper trading feed.

./derivbot.exe --mode paper --symbol jump10 --load-run run_20260622_080000 --rank 1
